# v0.1.8 — the embed release (Phase 1 of the stratahub integration)

*2026-09-21. Status: LIVE 2026-09-22 at `https://cdn.adroit.games/mhs/end/v0.1.8/` (launcher: `index.html`); the shipped player is archived as `ceremony_v7.html` + `lib/player_v7.js`.*

Why: stratahub is wiring the ceremony in after Unit 5 (plan:
`stratahub/docs/mission-hydrosci/mhs-end-ceremony-plan.md`). It needs the
bundle to (1) run inside a host page it controls, from a path of its choosing,
(2) accept the student's scores from a same-origin endpoint without waiting on
grading, (3) give the student a way back, and (4) never depend on a public CDN.

## What changed

| Area | Change |
|---|---|
| `lib/embed.js` (new) | The one script a host loads: builds the DOM + CSS (moved out of `ceremony.html`), loads the bundle's own files in order, fetches scores, resolves, starts the player, emits events. Contract in `docs/embed-api.md`. |
| `lib/resolver.js` | `rebindUnit`, `rebindStars`, `variants` for late binding; `resolve` unchanged. |
| `lib/player.js` (v7) | `start(script, opts)`: `opts.base` prefixes every asset URL; hooks (`beforeUnit`, `beforeCelebration`, `onStarted`, `onFinished`, `onFailed`, `onExit`); Exit control (`#exitBtn`); `opts.dev`; the F/R hint hidden unless dev. |
| `lib/vendor/`, `assets/env/` | Babylon 9.27.1 + loaders, the environment map and the particle sprite, vendored (were the public Babylon CDN and playground host). |
| `ceremony.html` | Now a two-line host page over the embed (`?profile=`, `?dev=1`). |
| `ceremony-definition_v6.js` | `u3.garden` bar 3 → 2.5 (team doc D5). Audio unchanged. |
| `index.html` | Footer no longer links the frozen archive (repo-only from now on). |
| `tools/stage-dist.sh` | Staging is a script: current show only, archive and script-v3 clips excluded (−4.5 MB). |
| `tests/resolver.test.cjs` | Garden-bar tests, late-binding tests. |

## Verification

- `node tests/resolver.test.cjs` green.
- Local server at the repo root: `ceremony.html?profile=all-high` and
  `?profile=no-data` load with no console errors, Begin enables, the show
  runs; the Exit control appears only when `returnUrl`/`onExit` is given.
- Late binding: a host page mounted with a `scoresUrl` that first answers
  `pending` with no items and later `ready` with all-high items plays Jasper's
  B lines (already resolved before the change) and Tera's A lines, and the
  star board fills — see `tests/late-binding.html` driven by Playwright.
