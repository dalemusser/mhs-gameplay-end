# v0.1.9 — CORS image loads (the host-page freeze)

*2026-09-22. Status: built and staged; upload pending.*

**Symptom (Dale, on the stratahub host page):** the cold open played, the
company walked to their marks, then nothing — no speaker, no line. Standalone
on the CDN the same bundle played through.

**Cause.** The host page serves the bundle through a same-origin content path
(`/missionhydrosci/content/end/vX.Y.Z/…`) that redirects to the CDN. The
player's holo images were plain `new Image()` loads (no `crossorigin`), and an
image that crosses an origin during a redirect is tainted for canvas use.
`drawImageSlide` draws them onto the wall canvas and Babylon uploads that
canvas as a texture; WebGL refuses a tainted canvas with a `SecurityError`.
The first beat with holo images is Toppo's opening line, so `enterBeat(0)`
threw before it showed the speaker or text. GLBs, the environment map and
Babylon's own textures were unaffected because they are CORS/XHR loads.

**Fix (player v8).** `img.crossOrigin = 'anonymous'` on the holo image loads
(`holoImage()`), and `extractTint` can no longer throw. The CDN already
answers CORS for the workspace hosts (verified 2026-09-22), and standalone the
images are same-origin, so both cases are clean. `EMBED_V` → 2.

**Hosting note (docs/embed-api.md):** a host page's origin must be allowed by
the CDN's CORS configuration, because the bundle's images, models and data
are all CORS loads. Reviewer pages on the CDN itself need nothing.

**Verification.** Resolver tests green; standalone smoke on a local server
plays through the cold open into Toppo's line with the CORS attribute set;
the real check is the host page on Dev MHS after the upload.

**Release.** `tools/stage-dist.sh 0.1.9`; upload `dist/v0.1.9/` to
`mhs/end/v0.1.9/`; Sync from S3; select v0.1.9 on the collection. Snapshot
the plain pair to `_v8` after the upload.
