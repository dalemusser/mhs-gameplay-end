# v0.2.1 — autostart

*2026-09-24. Status: LIVE at `https://cdn.adroit.games/mhs/end/v0.2.1/`
since 2026-09-25 (sweep 103/103); player v10, `EMBED_V` 4; stratahub's host
page passes `autostart: true` (deployed 2026-09-25). Shipped player archived
as `ceremony_v10.html` + `lib/player_v10.js`.*

The student arrives at the ceremony from the game's end screen (Continue) or
from the launcher (Watch). Either way they just pressed a button, so a second
one — Begin — was a speed bump (Dale, 2026-09-24: autostart on every arrival
regardless of where it is launched from). The Begin click existed for one
reason: browsers refuse to play sound until the page has a user gesture.

## What changed

- `mount(el, { autostart: true })` (`lib/embed.js` → `opts.autostart` in
  the player). When the bundle is ready the player plays a 100 ms silent WAV
  (`probeAudio`): if the browser allows it, `beginShow()` runs at once —
  the same path as the Begin click (cold open, `onStarted` event, the
  show). If the browser refuses (`NotAllowedError`), or cannot play the
  probe at all, the Begin button stays, enabled, with a "Tap Begin to
  start." note under it. Never a stuck black page.
- The Begin click handler is the same `beginShow()`; `showBegun` makes the
  two paths race-safe (a click during the probe cannot start the show twice).
- Standalone `ceremony.html` takes `?autostart=1` for testing; the CDN
  launcher (`index.html`) is unchanged, so reviewers still get Begin.
- StrataHub's host page (`/missionhydrosci/ceremony`) passes
  `autostart: true` on every arrival.

## What to expect per browser

Chrome and Edge let a page play sound when the user has interacted with the
site (the game itself, for an hour) or when the navigation that opened the
page came from a click — both true for a student. Safari, including iPad,
generally needs a tap on the page itself: those students see Begin, as
before. The probe decides at run time, so nothing is guessed.

## Verification

- Chrome: open `ceremony.html?profile=…&autostart=1` from a link on another
  page (a click) — the show begins with no Begin; the console shows no
  autostart line.
- Chrome, typed URL in a fresh profile (no engagement): Begin stays with the
  note; the console shows `autostart deferred to Begin (NotAllowedError)`.
- The Begin path is unchanged: `ceremony.html?profile=…` without the flag.
